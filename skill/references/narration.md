# Narration word lists

Use this file alongside the narration rules in SKILL.md. The check step flags the most common problems, but it can't judge meaning, so read your script aloud as well.

## British spelling

| Write | Not |
| --- | --- |
| organisation, organise, recognise, prioritise, summarise, authorise | -ize forms |
| colour, favour, behaviour | color, favor, behavior |
| programme (a scheme), program (software only) | program for a scheme |
| cheque | check (for payment) |
| cancelled, labelled, totalled | canceled, labeled, totaled |
| centre, metre | center, meter |
| licence (noun), license (verb) | license as a noun |
| enrol, fulfil | enroll, fulfill |
| analyse, catalogue | analyze, catalog |

Dates: say "14 March 2026" rather than "March 14th". Money: "£1,250" is read aloud as "one thousand two hundred and fifty pounds", so check the voice output.

## Terms to use consistently

- **Gift Aid**, **Gift Aid declaration**, **HMRC**.
- **Gift Aid Small Donations Scheme** in full the first time, then **GASDS**. Add `"GASDS": "G A S D S"` (or the pronunciation the team prefers) to the lexicon.
- **donor**, **donation**, **collection**, **claim**, **top-up** (for the GASDS payment).
- The exact on-screen label for any button, tab or heading, in the same capitalisation.

## Phrases to avoid, and what to say instead

| Avoid | Say |
| --- | --- |
| simply, just, easily, quickly | (leave it out) |
| seamless, powerful, robust, leverage | say what it actually does |
| click here, go ahead and | use, choose, select, open |
| you are entitled to, this is compliant | the figure we calculate, check this against your records |
| In this video we will... | say what the screen is for |
| e.g., i.e., etc. | for example, that is, and so on (the voice reads abbreviations badly) |
| data (as a vague noun) | donations, records, figures |
| exclamation marks | full stops |
| em dashes, en dashes | a full stop or a comma |

## Pacing

- About 2.3 words a second at the default speed of 0.95, so roughly 140 words a minute.
- Sentences of 8 to 20 words. Anything longer is hard to follow without seeing text.
- Leave the camera time to settle: after a move, say at least a few more words about the thing you just moved to before moving again.
